5) Middleware — role check

php artisan make:middleware CheckRole

app/Http/Middleware/CheckRole.php

<?php

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;

class CheckRole
{
    public function handle(Request $request, Closure $next, $role)
    {
        $user = $request->user();
        if (!$user || $user->role !== $role) {
            return response()->json(['message' => 'Forbidden'], 403);
        }
        return $next($request);
    }
}


Register middleware in app/Http/Kernel.php in $routeMiddleware:

9.1 Axios instance & auth helpers

src/api.js

import axios from 'axios';

export const api = axios.create({
  baseURL: 'http://localhost:8000/api',
  // If you use Sanctum cookies: withCredentials: true
  // withCredentials: true,
});

// attach token if present
export function setAuthToken(token) {
  if (token) {
    api.defaults.headers.common['Authorization'] = `Bearer ${token}`;
    localStorage.setItem('token', token);
  } else {
    delete api.defaults.headers.common['Authorization'];
    localStorage.removeItem('token');
  }
}

export function saveRole(role) {
  localStorage.setItem('role', role);
}

Sanctum কি কাজ করে?
1) Login করলে Token দেয়

React যখন Login API কল করে, Sanctum একটি token দেয়।
React সেই token localStorage / cookie তে রাখে।

2) Protected Routes নিরাপদ রাখে

যেমন:

/api/admin/dashboard

/api/seller/products

/api/customer/orders

এগুলো Sanctum ছাড়া সিকিউর হবে না।

3) Multi-auth Role Handle করা সহজ

Admin, Seller, Customer আলাদা আলাদা role set করতে পারবেন।

Sanctum ব্যবহার করলে React সহজে role-based API access করতে পারে।

4) Session ছাড়া Authentication

React App-এ PHP session কাজ করে না।
Sanctum token দিয়ে দেয় → React সেই token পাঠায় → Laravel user verify করে।
